
# Login Form – Glassmorphism UI

A simple and modern login form built with HTML and CSS, featuring a glassmorphism design.

## Features

- Username and password input fields
- Password masking
- Remember Me checkbox
- Forgot Password and Register links
- Glassmorphism effect
- Hover and focus interactions
- Responsive layout

## Built With

- HTML5
- CSS3
- Google Fonts – Poppins
- Boxicons

## Project Status

This project is a front-end practice exercise. Future improvements may include JavaScript interactions and form validation.
